ТЕСТЫ ДЛЯ mathtool.py

1. Вызов справки
   Команда: python mathtool.py
   (то же самое будет и для python mathtool.py --help)
   -> печатается текст справки (как пользоваться программой)
   -> код 0

2. Неизвестная команда вместо solve
   Команда: python mathtool.py calc
   -> ОШИБКА: неизвестная команда
   -> код 1

3. Неверный набор параметров (пропущен, лишний или неизвестный)
   Команда: python mathtool.py solve -a 1 -b 2
   -> ОШИБКА: неверный набор параметров
   -> код 1

4. Исходные данные не являются числами
   Команда: python mathtool.py solve -a abc -b 1 -c 1
   -> ОШИБКА: коэффициент не является целым числом
   -> код 1

5. Исходные данные вне допустимого диапазона
   Команда: python mathtool.py solve -a 50000 -b 1 -c 1
   -> ОШИБКА: значение вне допустимого диапазона
   -> код 1

6. Квадратное уравнение с двумя корнями
   Команда: python mathtool.py solve -a 1 -b -3 -c 2
   -> Уравнение квадратное
      D = 1
      x1 = 2.000
      x2 = 1.000
   -> код 0

7. Квадратное уравнение с одним корнем
   Команда: python mathtool.py solve -a 1 -b -2 -c 1
   -> Уравнение квадратное
      D = 0
      x = 1.000
   -> код 0

8. Квадратное уравнение без действительных корней
   Команда: python mathtool.py solve -a 1 -b 0 -c 5
   -> Уравнение квадратное
      D = -20
      Действительных корней нет
   -> код 0

9. Линейное уравнение с одним корнем
   Команда: python mathtool.py solve -a 0 -b 2 -c -4
   -> Уравнение линейное
      x = 2.000
   -> код 0

10. A = 0 и B = 0 - уравнения не существует
    Команда: python mathtool.py solve -a 0 -b 0 -c 5
    -> ОШИБКА: это не уравнение, неизвестное отсутствует
    -> код 1
